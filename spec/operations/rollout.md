# Ownership, pilot, and rollout gates

`pH34r-pH/specified-development` owned common original tooling, documentation, fixtures and releases under Apache-2.0. Consumer constitutions/domain rules and the existing execution owner's infrastructure remained with their owners. GitHub Releases were the planned archive/checksum/lock distribution channel; no hosted service, credentials or new infrastructure charges were needed for the foundation.

The smallest coherent pilot used a synthetic complete mature product with two features and a shared contract/asset, plus isolated sanitized copies of two existing Spec Kit installations. It tested the whole lifecycle, source directory, replacement commands, native execution/issue dry projection, receipts, cache/cost, staged upgrade/recovery and scoped behavioral regeneration. The product specification stayed complete; only the pilot's environmental scope was small.

| Gate | Evidence and permitted boundary |
| --- | --- |
| G0 Foundation | Confirmed destination/license; allowlisted generic payload; exact-head CI; draft PR. No release, consumer mutation or deployment. |
| G1 Distribution | Pinned upstream/toolchain/dependencies/components, digests, licenses and clean source build; staged inventory and effective integration assets. |
| G2 Directory | Independent discovery/closure/link/asset/source-map/freshness/retention tests; repository and optional renderer parity; no undocumented adapter behavior. |
| G3 Recovery | Wrong version/tamper/interrupted promotion/rollback and concurrent edit tests with exact restoration proof. |
| G4 Complete pilot | Complete isolated synthetic lifecycle and existing-installation compatibility; independent source-excluded regeneration proof restricted to the declared module. |
| G5 Adoption | A separate consumer-owned scoped PR reconciled authority/history, existing features, active agent assets, accepted build retention and permissions. No automatic broad rollout. |
| G6 Activation | Existing owner positively enforced exact model/settings/permissions, native parents, RED-only/no-code leaves, pagination and completion predicates. Unsupported cases remained blocked; no second scheduler. |
| G7 Publication | Exact reviewed release/site/wiki destination and source/public inventory, qualified renderer/lock, auth, before-hash drift check and rollback; independent authorization per requested publication. |

Every consumer adoption was separate from application implementation and separately coordinated with its current owner. Public evidence excluded private project research, credentials, infrastructure topology and raw logs. Successful rendering did not prove behavioral regeneration or deployment. Code remained retained throughout.
